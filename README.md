## Описание

YOLOv8 Webcam Detection — это легковесное desktop-приложение для детекции 80 классов объектов (COCO dataset) в реальном времени.

Главная особенность проекта — **решение проблемы отображения кириллицы в OpenCV**. Поскольку стандартный `cv2.putText` не поддерживает русские символы, в проекте реализован гибридный рендеринг через `Pillow (PIL)` с автоматическим поиском системных шрифтов для Windows, Linux и macOS.

## ⚙️ Как это работает (Технические детали)

1. **Детекция и Трекинг**: Используется модель `yolov8n.pt` (nano) для баланса между скоростью и точностью. Включен режим `persist=True` для присвоения уникальных ID отслеживаемым объектам между кадрами.
2. **Кроссплатформенный рендеринг**: Функция `put_ru_text` конвертирует кадр OpenCV (NumPy array) в формат PIL, применяет подходящий системный шрифт (Arial, DejaVu или San Francisco) и возвращает кадр обратно в BGR.
3. **Оптимизация производительности**:
   - Реализован механизм **пропуска кадров** (`frame_skip`) через OpenCV Trackbar, позволяющий жертвовать частотой обновления ради повышения FPS на слабых GPU.
   - Входной кадр масштабируется до 1280x720 для стабильной работы инференса.
4. **Надежная запись видео**: При инициализации `VideoWriter` используется кодек `XVID`. Если он недоступен в системе, скрипт автоматически fallback-ит на `MJPG`, предотвращая падение приложения.

## Возможности

- 🔍 Детекция 80 классов объектов в реальном времени
- 🔄 Multi-object tracking с сохранением уникальных ID
- 🇷🇺 **Полная поддержка русского языка** в интерфейсе (названия классов, подсказки)
- 📊 Отображение текущего FPS в углу экрана
- 🎚️ Интерактивные трекбары для настройки `Confidence Threshold` и `Frame Skip` без перезапуска
- 📹 Автоматическая запись результата в `detect.avi` с защитой от ошибок кодека
- 🛡️ Graceful degradation: при сбое инференса одного кадра приложение не падает, а продолжает работу

## Использование

После запуска приложения вы увидите окно с видео с веб-камеры и наложенной информацией о распознанных объектах.

* Нажмите `q` для выхода из приложения
* Используйте трекбар `"Confidence"` для настройки порога "уверенности" (от 0 до 100%)
* Используйте трекбар `"Frame Skip"` для настройки пропуска кадров (чем выше значение, тем выше производительность, но
  ниже точность)

## Особенности интерфейса

* В левом верхнем углу отображается текущее значение FPS
* Распознанные объекты выделены цветными рамками
* Под рамкой отображается название объекта на русском языке, вероятность распознавания и ID объекта (при отслеживании)

## Как это работает

1. Приложение открывает доступ к веб-камере
2. Каждый кадр изменяется до разрешения 1280x720
3. YOLOv8 обрабатывает кадр и определяет объекты
4. Для каждого распознанного объекта:
    * Рисуется цветная рамка
    * Добавляется метка с названием на русском языке
    * Отображается вероятность распознавания
    * При включенном отслеживании показывается ID объекта
5. Обработанный кадр записывается в видеофайл `detect.avi`
6. Кадр отображается в окне приложения

## Настройка под свои нужды

Вы можете изменить следующие параметры в начале скрипта:

```python
# Модель для использования (можно заменить на другие версии YOLOv8)
model = YOLO('yolov8n.pt')

# Целевое разрешение видео
output_width, output_height = 1280, 720

# Начальный порог уверенности (по умолчанию 0.48)
conf_threshold = 0.48

# Начальное значение пропуска кадров (по умолчанию 1)
frame_skip = 1
```
